# Projetos HTML

Coleção de projetos desenvolvidos em **HTML** para prática e aprendizado de construção de páginas web.  
O objetivo é exercitar conceitos de estruturação de conteúdo e criação de interfaces simples.

## Tecnologias Utilizadas
- **HTML5** → Estrutura e marcação das páginas  
- **CSS3** *(quando aplicado)* → Estilização e layout das páginas  
- **JavaScript** *(quando aplicado)* → Interatividade básica  

## Objetivos
- Praticar o uso correto das tags HTML  
- Criar páginas com layout organizado  
- Aplicar conceitos básicos de estilização e interatividade
